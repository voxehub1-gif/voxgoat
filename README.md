# VOXGOAT - Premium Full-Stack Gaming Platform

VOXGOAT is a lawful, free-to-play social gaming platform. It features user authentication via Fast2SMS, tournament management, and a robust admin dashboard.

## Tech Stack
- Next.js (App Router)
- React & TypeScript
- Tailwind CSS
- Supabase (PostgreSQL, Auth, Storage)
- Fast2SMS API
